# 🛍️ Ecommerce (Django Project)

A simple and functional Ecommerce web application built using **Django**.  
This project includes product listings, cart features, and basic store functionality — easy to run, customize, and extend.

---

## 🚀 Features

- Display products with images, price, and details  
- Add items to cart  
- View and manage cart items  
- Clean and simple UI  
- Django-based backend  
- Easy to extend: add categories, checkout system, user login, etc.
